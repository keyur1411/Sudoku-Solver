# 🧩 Sudoku Solver

A simple Sudoku Solver built with **HTML, CSS, and JavaScript**.
Enter numbers in the grid and click **Solve** to see the solution instantly.
You can also use **Clear** to reset the board.

---

## ⭐ Features

* 9×9 Sudoku grid
* Solves puzzle using backtracking
* Highlights wrong inputs
* Simple and clean interface
* Clear button to reset the grid

---

## 🚀 How to Run

1. Download or clone the project
2. Open **index.html** in your browser
3. Enter your puzzle → click **Solve**
4. Click **Clear** to try again
